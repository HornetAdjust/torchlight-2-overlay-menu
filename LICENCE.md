## 🧩 About

**Torchlight 2 Companion** is a curated list of Torchlight 2 open-source tools:

- **Overlays** — on-screen helpers, layout notes, loot tracker, minimap overlay
- **Quality-of-Life Helpers** — inventory sorter, stash manager, overlay notes
- **Research Notes** — build layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### ESP
- Loot Filter — highlight valuable items on the ground
- Minimap Overlay — enlarged minimap with markers
- Damage Numbers — floating combat text for study
- Auto-Pickup — automatically collect gold and potions

### Wallhack
- Custom HUD — rearrange health, mana, and skill bars
- Buff Tracker — monitor active buffs and debuffs
- Cooldown Timer — visual cooldown bars for skills
- Enemy Health Bars — show health bars above enemies

### Aimbot
- Inventory Sorter — one-click sort for backpack and stash
- Stash Search — filter items by name or attribute
- Quick Sell — sell all junk items with a hotkey
- Respec Notes — track skill and stat point allocations
